## O que cada diagrama mostra

- **Casos de uso:** quem faz o quê no sistema (menu principal, partida, menu de pausa, árvore de habilidades e salvamento), com os requisitos funcionais relacionados.
- **Sequência:** como os menus, o controle do jogo, o personagem, os inimigos, a progressão e o save trocam mensagens, do início do jogo até o fim de uma fase.
- **Atividades:** o fluxo de atividades do menu principal até o fim da fase, dividido em fluxo geral, "jogar a fase" e menu de pausa.

Os diagramas em Mermaid são exibidos automaticamente pelo GitHub.
